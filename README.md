# Tutoriais TGA - README

## Visão Geral
Página web centralizando tutoriais, recursos e ferramentas para o sistema TGA (TGA Sistemas). Oferece acesso rápido a:

- Manuais técnicos
- Links institucionais
- Ferramentas de suporte
- APIs integradas
- Downloads essenciais

## Tecnologias Utilizadas
| Tecnologia | Finalidade |
|------------|------------|
| HTML5 | Estruturação do conteúdo |
| CSS3 | Estilização e layout responsivo |
| JavaScript | Interatividade e dinamismo |
| Font Awesome | Ícones visuais |
| Firebase | Notificações em tempo real |
| Google Analytics | Métricas de acesso |
