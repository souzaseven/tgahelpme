**Módulo do Sistema:**
FINANCEIRO
----------

**Objetivo**
REGISTRAR BOLETO VIA API DE COBRANÇA
------------------------------------

**Passos para Solução**

1. Acesse o menu **Movimentos → Integração Bancária → Remessa - Cobrança Eletrônica**.
2. Selecione o **Portador** configurado para utilização da **API de Cobrança**.
3. Informe a **Data de Emissão** ou **Data de Vencimento** desejada.
4. Clique em **Filtrar** para que o sistema exiba apenas os **boletos que ainda não foram registrados pela API**.
5. Marque os boletos que deseja **registrar**.
6. Clique em **Enviar** ou **Gerar**, conforme o nome do botão na versão do seu sistema.
7. O sistema processará o envio e os **boletos selecionados serão registrados automaticamente via API**.

---

**Observações**

* Após o registro, verifique na tela **Consulta Boleto API** se os boletos foram efetivamente registrados.
* Também é possível confirmar o registro diretamente no **aplicativo ou portal do banco**.
* Esse processo garante que os boletos estejam ativos para cobrança e disponíveis para pagamento pelos clientes.
