Módulo 1 Usuários

Controle de Usuários

Como consultar, redefinir senhas e desativar cadastros no painel QLoudMe.

Acessando o painel

Acesse tga.qloudme.com.br e vá até a seção Usuários. Nela você visualiza todos os cadastros ativos e inativos do sistema.

Informações disponíveis na listagem

A tabela exibe as seguintes colunas para cada usuário:

Campo O que mostra
UsernameLogin do usuário no sistema
Nome CompletoNome cadastrado
ClienteEmpresa / cliente vinculado
EmailE-mail de contato
OUUnidade organizacional
StatusAtivo ou inativo
Data CriaçãoQuando o cadastro foi criado
Data DesativaçãoQuando foi desativado (se aplicável)
AçõesBotões de reset de senha e desativação

Ações disponíveis

🔑 Botão da Chave — Resetar Senha

Clique no ícone de chave ao lado do usuário para redefinir a senha. Você pode usar a senha padrão do sistema ou escolher uma senha personalizada para aquele usuário.

✖ Botão X Vermelho — Desativar Cadastro

Clique no X vermelho para inativar o cadastro do usuário. O usuário perde o acesso imediatamente, mas o registro permanece no sistema para consulta.

⚠️

Desativar um cadastro é diferente de excluir. O histórico fica registrado e o acesso pode ser reativado se necessário. Confirme sempre antes de clicar no X.

💡

Para localizar um usuário rapidamente, use o campo de busca no topo da listagem e pesquise pelo username ou nome do cliente.

Módulo 2 Serviços

Serviços Windows

Como reiniciar os serviços do servidor principal TGA pelo painel QLoudMe.

Onde fica?

No painel tga.qloudme.com.br, acesse a seção Serviços Windows. É nessa área que você reinicia os serviços do servidor principal quando necessário.

Serviços disponíveis

Os quatro serviços principais que você vai gerenciar são:

TGA — Server API WEB
Responsável pela comunicação via API do sistema web.
TGA — Server Cloud
Serviço principal da nuvem TGA.
TGA — Server Integrador PDV
Integração com sistemas de ponto de venda.
TGA — Server WhatsApp
Serviço de comunicação via WhatsApp.

Quando reiniciar?

Reinicie um serviço quando o cliente relatar que aquela funcionalidade específica parou de responder. Por exemplo: se o WhatsApp parou de enviar mensagens, reinicie o TGA — Server WhatsApp.

🚨

Reiniciar um serviço interrompe brevemente a funcionalidade para todos os usuários. Evite fazer isso em horário de pico sem necessidade. Verifique primeiro o site de monitoramento para confirmar que o serviço realmente está com problema.

Passo a passo para reiniciar

Confirme o problema

Acesse o monitoramento em monitoramento.qloudme.com.br e verifique qual serviço está com sinal de erro.

Acesse Serviços Windows

No painel QLoudMe, clique em Serviços Windows.

Reinicie o serviço correto

Localize o serviço que está com problema e clique em Reiniciar.

Verifique o monitoramento

Aguarde alguns segundos e confira se o sensor voltou ao verde no painel de monitoramento.

✅

Se o sensor voltar ao verde e o cliente confirmar que funcionou, o atendimento está encerrado para esse caso.

Módulo 3 Sessões

Usuários Conectados e Limpeza de Perfil

Monitore sessões TSPlus, aja em travamentos e limpe perfis corrompidos.

Usuários Conectados — Monitor de Sessões TSPlus

Na seção Usuários Conectados do painel QLoudMe, você acessa o Monitor de Sessões TSPlus. Nele é possível:

  • Ver o status de cada farm (online / offline)
  • Ver a quantidade de clientes conectados em cada farm
  • Buscar em qual servidor um cliente específico está pesquisando — basta digitar o código do cliente no campo de busca

Ações disponíveis em cada sessão

Clicando em Detalhes da Farm e depois em Ações, você tem três opções para cada sessão ativa:

Ação O que faz Quando usar
👁 Visualizar Tela Abre a visualização da tela do cliente em tempo real Para ver o que o cliente está vendo e ajudar remotamente
🔌 Desconectar Acesso Desconecta a sessão do usuário Quando o cliente está travado mas a sessão ainda existe
✖ Encerrar Sessão Finaliza a sessão completamente Muito usada quando o usuário trava e fica com tela preta ao tentar logar
⚠️

Tela preta ao logar é um dos problemas mais comuns. A solução é encerrar a sessão ativa do usuário nessa tela — ele conseguirá logar normalmente em seguida.

Limpeza de Perfil de Usuário

A seção Limpeza de Perfil de Usuário é usada em casos específicos: quando o usuário perde a base de dados configurada e precisa ficar adicionando novamente toda vez que faz login.

💡

Esse recurso é usado raramente. Só acione quando o cliente relatar que as configurações somem a cada novo login. Limpar o perfil força a recriação do perfil do usuário no servidor, resolvendo a perda de base.

Módulo 4 Servidores

Servidores TGA, Data Center e Auditoria

Entenda a infraestrutura, acesse servidores de clientes e consulte o histórico de logins.

Acesso Servidor TGA (Mobile / FV)

A seção Acesso Servidor TGA lista todos os clientes que utilizam o tgafv (mobile on-smart / cliente web). Cada cliente com o mobile ativado possui um servidor exclusivo dedicado a ele e ao serviço do FV.

Botão O que faz
🔗 Conectar Acessa diretamente o servidor do cliente para fazer ajustes, reiniciar serviço e similares
📡 Testar Testa a comunicação com o servidor. Se der erro, o mobile do cliente também vai parar de funcionar
🚨

Se o botão Testar retornar erro, o aplicativo mobile do cliente para de funcionar imediatamente. Use o botão Conectar para acessar o servidor e investigar o problema.

Data Center QLoudMe

A seção Data Center QLoudMe lista todos os servidores da infraestrutura. Conheça cada um:

FIREBIRD & BASECLIENTE
Armazena todos os bancos de dados e configurações dos clientes.
FARM 1 a 9
Servidores da farm onde os usuários se conectam via TSPlus.
RONDONÓPOLIS — REVENDA
Servidor dedicado à revenda de Rondonópolis.
GATEWAY TSPLUS SECURITY
Firewall responsável por liberar clientes bloqueados por IP ou acesso indevido.
🔥

Se um cliente relatar que está sendo bloqueado ao tentar acessar, verifique o Gateway TSPlus Security para liberar o IP dele.

Auditoria de Logins

Na seção Auditoria de Logins você consegue consultar a última vez que um usuário fez login pelo sistema web. É útil para:

  • Confirmar se um usuário de fato acessou o sistema recentemente
  • Investigar reclamações de acesso negado ou conta inativa
  • Verificar se o usuário não está usando o acesso há tempo
